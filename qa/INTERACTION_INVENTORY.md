## I. Known issues found during inventory (detail in `QA_REPORT.md`)

- **I-1** (low–medium): no `scroll-margin-top` — anchor jumps land section headings under the sticky nav (seen in `vault-1280.png`: `03 THE VAULT` half-hidden).
- **I-2** (low): fixed low-motion toggle overlaps page content at bottom-right (register table at 1280 px, stat card at 390 px).
- **I-3** (low, latent): vault 3D renders max 8 cards (`slice(0,8)`) with no `+N EARLIER` indicator — docs 9+ vanish from the 3D view (table still shows all).
- **I-4** (low): malformed `expected_blob_id` + file → verdict `TAMPERED` instead of a 400 (verify-by-hash alone correctly 400s). Verified live via curl.
- **I-5** (low): `verify-chain` has no `try/catch` — a network failure would not produce a UI message (code-reading only).
- **I-6** (low, constitution deltas): no hero CTAs, no `NYAYA—SEAL` logo block, no `aria-current` on nav, drag-over doesn't change the dropzone label text, no crack edge on the TAMPERED stamp, no tampered-slab tilt, no ←/→ selection (D7). All cosmetic vs the constitution; none breaks a workflow.

No app code was changed during QA. No bug was fixed (the one FAIL is a missing minor feature, left for the builder).
